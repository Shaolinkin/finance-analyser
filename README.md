Python Tool that analyses bank statement CSVs and visualises expenses.

<img width="622" height="473" alt="image" src="https://github.com/user-attachments/assets/927d1f50-6f97-4161-bad0-6b75cf473add" />

Features:
- Parses and categorises transactions via keyword matching.
- Calculates the total income, expenses and net balance per month.
- Visualises expenses via different charts, e.g. bar chart, pie chart.

How to run:
1. Clone repo
2. pip install pandas matplotlib
3. Add bank statement CSV to the data/ folder and name it transactions.csv
4. Run python main.py

Tools used:
- Python
- Pandas
- Matplotlib
